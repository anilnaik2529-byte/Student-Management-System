# Student Management System

A full-stack Student Management System developed using React, Spring Boot, MySQL, and JWT Authentication. This application allows users to securely manage student records through CRUD operations.

## Features

- User Registration
- User Login with JWT Authentication
- Protected Routes
- Add Student
- View Students
- Update Student
- Delete Student
- Search Students
- Pagination
- Form Validation
- Responsive User Interface
- Toast Notifications

## Technologies Used

### Frontend
- React.js
- React Router
- Axios
- CSS
- React Toastify

### Backend
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate

### Database
- MySQL

## How to Run

### Backend

1. Open the `backend` folder.
2. Configure MySQL in `application.properties`.
3. Run the Spring Boot application.

### Frontend

1. Open the `frontend` folder.
2. Install dependencies:

```bash
npm install
```

3. Start the React application:

```bash
npm start
```
